# 神经元
多个树图：接受信号
单个轴突：输出信号
轴突 = f([信号1, 信号2, ...])
**唯一的决定了神经元的输出是否正确：参数 = 权重（上一层的输入*当前神经元数量） + 偏置（当前神经元数量）**

# 向前传播
从输入层一直传递到输出层，即前向传播。

为什么要用矩阵运算？矩阵运算性能非常高，可以使用GPU加速运行。

# 剃度下降
梯度下降：沿着函数在当前点处最速下降方向（即负梯度方向）移动，使得函数的值逐步减少。

神经网络最终计算出来的为预测值，与真实值的差异，就是损失函数。
参数 影响 损失度。

剃度下降为了让损失度降到最低，通过反向传播，实现剃度下降。
学习率：剃度下降的幅度。

# 训练模式和框架
随机梯度下降 SGD：每一步只取1个样本算剃度更新参数
批量梯度下降 BGD：每一步取所有样本算剃度更新参数
**小批量梯度下降（大模型主流）**：每一步取一批切片跑，跑完直接更新参数

灾难性遗忘：训练时神经网络忘记了之前训练完成的样本。
