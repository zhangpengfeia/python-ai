# 模型

qwen3-8b ， 32b 怎么选？
一般从大往小试模型，32b ok -> 14b ok -> 8b no
模型蒸馏 32b -> 8b：让强的回答，把问题和回答作为训练数据集，给弱的进行训练

总结：没招的时候，节省成本，特定场景，会使用微调

insruct: 指令遵循，
xxx-xxb-instruct: 指令遵循模型，千问不带后缀就是指令微调，出厂就微调了

什么是参数：y = ax+b ==> a,b 是参数(x是输入，y是输出)

# 数据准备
1. 人工编辑，审核（效率低，成本高）
2. 流行：合成数据（让llm帮助造数据），如果有真实数据（业务系统的真实对话，文档）
    =》数据提取
    =》数据清洗
    =》格式转换 ，转换成模型支持的格式
    =》只有问题没有答案，100条问题 =》让llm做答案，扩展成N条数据，1000条数据 ，抽检5-10%，人工核查

    注意：
    数据配比：
        推理和非推理：8:2
        灾难性遗忘：一直训练，某些领域训练前能做到，训练后丧失能力
    
    数据量：
        几百条到几万条，常用几千条 == 》必须高质量
        500条高质量，比1万条低质量的效果好
